# Contributing to void-web

Hi there!

To be completely honest, this project has quite a few flaws, some messy logic, and a solid amount of legacy code. It was built fast, and many parts definitely need a proper refactor.
If you are not afraid of some "spaghetti architecture" and want to help clean it up, you are more than welcome! We are happy to review any pull requests - whether it's fixing a minor bug, rewriting a sloppy component, or completely overhauling a feature.

Ideally, if it works, it’s best not to touch it; however, if you need it for learning purposes or simply have nothing else to do, feel free to make your own changes.
